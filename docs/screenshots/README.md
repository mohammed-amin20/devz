# Screenshot gallery

Automated, reproducible screenshots of every distinct **full-screen state** of the
devZ app, captured straight from the real Compose UI in both **dark** and
**light** themes.

> These PNGs are generated by a test — do not edit them by hand. Change the UI (or
> the fixtures in the test) and regenerate.

## How they are produced

| | |
|---|---|
| Harness | JVM unit test [`ScreenshotGalleryTest`](../../app/src/test/java/com/mohamed/devz/gallery/ScreenshotGalleryTest.kt) |
| Renderer | Robolectric 4.17 with `GraphicsMode.NATIVE` (real Skia rasterization, no device) |
| Capture | Roborazzi 1.76 `captureRoboImage()` |
| Application | [`GalleryTestApp`](../../app/src/test/java/com/mohamed/devz/gallery/GalleryTestApp.kt) (plain `Application`, no Hilt) |
| Viewport | `w411dp-h891dp-420dpi` → **1078 × 2338 px** |
| Locale / font scale | `en-US`, font scale `1.0` |
| Themes | `DevzTheme(themeMode = DARK)` and `DevzTheme(themeMode = LIGHT)` |

Each screen is rendered in a *fresh composition per theme* (one test per
screen per theme), which guarantees the light frame is genuinely recomposed.
All screens use the same fixtures as the `@Preview` functions in the screen
source files.

### The bottom navigation bar

The in-app tab screens captured with the bar (Feed, View profile,
Notifications, and the admin profile) are drawn with the home shell's **bottom
navigation bar** underneath them, including the raised cyan **Add** button at
center. The production bar lives inside the Hilt-bound `HomeContent`, so the test
uses a small visual replica (same icons, colors, height, selected-tab state and
center FAB) rather than importing it.

### Screens that are not captured

- **Home shell (as a whole)** — `HomeContent` embeds Hilt-backed screens
  (`ViewQuestionsScreen`, `NotificationsScreen`, `JobsScreen`,
  `ProfileScreen`) and cannot be rendered in a plain Robolectric test. Its
  constituent screens are captured individually instead (with the bar).
- **Jobs list** — `JobsScreen` has no stateless content split, so the jobs
  browse tab itself is not captured; only Job detail and Post job are.

## Regenerating

```bash
./gradlew :app:testDebugUnitTest --tests "*ScreenshotGalleryTest*"
```

Requires JDK 21 (Android Studio's JBR). The test writes directly into this
folder as `<screen>-content-{dark,light}.png`. On the first run Robolectric
downloads the Android 14 (`android-all-instrumented`) runtime jar into
`~/.m2/repository`, which can take several minutes.
